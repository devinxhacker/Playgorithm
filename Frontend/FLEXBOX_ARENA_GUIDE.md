# Flexbox Arena - Warrior Training Guide

## 🏰 Welcome to Flexbox Arena!

Flexbox Arena is an interactive learning game where you command warriors using CSS Flexbox properties. Just like Flexbox Froggy, but with a medieval warrior theme!

## 🎮 How to Play

1. **Read the Mission**: Each level has a specific objective
2. **Write CSS**: Enter Flexbox properties in the code editor
3. **Watch Warriors Move**: See real-time movement as you type
4. **Match Targets**: Align warriors with their colored targets
5. **Complete Level**: Warriors must overlap their matching targets

## ⚔️ Game Features

### 24 Progressive Levels
- **Levels 1-5**: Basic `justify-content` properties
- **Levels 6-10**: `align-items` and vertical alignment
- **Levels 11-15**: `flex-direction` and layout changes
- **Levels 16-20**: `flex-wrap`, `order`, and advanced positioning
- **Levels 21-24**: Master challenges with multiple properties

### Real-Time Feedback
- Warriors move instantly as you type CSS
- Color-coded targets match warrior colors
- Visual indicators for special properties
- Live CSS preview showing applied styles

### Interactive Elements
- **Hint System**: Get help when stuck
- **Level Selector**: Jump between completed levels
- **Progress Tracking**: See completion status
- **Reset Options**: Reset individual levels or all progress

## 🎯 Learning Objectives

### Core Flexbox Properties
- `justify-content`: Controls main axis alignment
- `align-items`: Controls cross axis alignment
- `flex-direction`: Changes main axis direction
- `flex-wrap`: Allows items to wrap
- `align-content`: Aligns wrapped lines
- `order`: Changes item order
- `align-self`: Individual item alignment
- `flex-grow`: Makes items grow to fill space

### Property Values
- `flex-start`, `flex-end`, `center`
- `space-between`, `space-around`, `space-evenly`
- `row`, `column`, `row-reverse`, `column-reverse`
- `wrap`, `nowrap`, `wrap-reverse`
- `stretch`, `baseline`

## 🏆 Completion System

- **Progress Tracking**: Visual progress bar and completion badges
- **XP System**: Earn experience points for each completed level
- **Master Achievement**: Complete all 24 levels to become a Flexbox Grandmaster

## 💡 Tips for Success

1. **Start Simple**: Begin with basic properties like `justify-content: center`
2. **Read Hints**: Use the hint system when stuck
3. **Experiment**: Try different values to see how they work
4. **Watch Movement**: Observe how warriors move in real-time
5. **Color Match**: Ensure each warrior reaches its matching target
6. **Combine Properties**: Later levels require multiple CSS properties

## 🚀 Getting Started

1. Navigate to `/game/flexbox-arena` in your dashboard
2. Start with Level 1: "Welcome to Flexbox Arena"
3. Follow the instructions and use CSS to move the red warrior to the red target
4. Progress through all 24 levels to master Flexbox!
